# Matriz_Trazabilidad_v1.0

Contiene la matriz inicial de trazabilidad del proyecto del semillero.

## Archivos
- `Matriz_Trazabilidad_v1.0.xlsx`: versión principal para gestión y filtrado.
- `Matriz_Trazabilidad_v1.0.csv`: versión tabular interoperable.
- `Matriz_Trazabilidad_v1.0.md`: versión legible para repositorio Git.

## Flujo de trazabilidad
Requisito → Objetivo → Caso de uso → HU → Módulo/Datos → Validación/Prueba → Estado.

La matriz incorpora las columnas `HU` (historias que cubren cada requisito, según el backlog v1.1) y `Pruebas` (IDs `P-XXX-NN` de la estimación v1.0). La columna `Estado` quedó en "Validado (Sprint 0)" tras la validación S0-01/S0-02.

## Estado
Matriz validada en el Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
