# Tareas Técnicas y Pruebas — v1.0

Descomposición inicial de las 36 Historias de Usuario refinadas.

## Estructura

HU → Tareas técnicas → Pruebas → Evidencia → Cierre

Cada HU tiene un documento independiente con:
- tareas técnicas,
- pruebas,
- criterio de cierre,
- pendientes de estimación/asignación.

## Importante

Esta versión todavía no asigna esfuerzo ni sprints. Esa decisión se realizará después de revisar dependencias y prioridades, evitando distribuir trabajo arbitrariamente.

T-026-01 y T-026-04 se dividieron en subtareas en la estimación consolidada (`../Estimacion_y_Dependencias_v1.0/`) y en la revisión de tareas grandes (`../Revision_Dependencias_y_Tareas_v1.0/`).
