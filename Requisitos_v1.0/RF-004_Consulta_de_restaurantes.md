# RF-004 — Consulta de restaurantes
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá permitir consultar los restaurantes registrados en la plataforma.

## Criterios de aceptación
1. El usuario puede acceder al listado de restaurantes.
2. El sistema muestra únicamente establecimientos registrados.
3. El usuario puede seleccionar un restaurante para consultar su detalle.

## Dependencias
- Base de datos de restaurantes.
- RF-005.

## Decisión (Sprint 0)
Cuando el usuario otorga permiso de ubicación, el catálogo puede ordenarse/filtrarse por cercanía (radio con expansión); sin permiso se muestra por popularidad/relevancia (V-03, V-04).
