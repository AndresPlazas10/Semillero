# RF-013 — Registro de preferencias
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario / Sistema

## Descripción
El sistema deberá permitir obtener o registrar información relacionada con las preferencias gastronómicas del usuario.

## Criterios de aceptación
1. El sistema puede almacenar preferencias definidas en el diseño.
2. Las preferencias pueden asociarse al usuario.
3. Se define si son explícitas, inferidas o una combinación.

## Decisión (Sprint 0)
Preferencias explícitas en onboarding (tipo de comida, rango de precio, restricciones) combinadas con preferencias inferidas progresivamente desde las interacciones; lo explícito domina mientras no haya historial (V-06).
