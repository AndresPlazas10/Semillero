# RF-021 — Gestión de horarios
**Tipo:** Requisito funcional  
**Prioridad:** Media-Alta  
**Actor principal:** Comerciante / Administrador

## Descripción
El sistema deberá permitir registrar y actualizar los horarios de atención.

## Criterios de aceptación
1. Un actor autorizado puede registrar horarios.
2. Puede actualizar horarios.
3. Los horarios quedan asociados al restaurante correcto.
4. Se pueden representar variaciones por día.
