# RF-022 — Gestión de ubicación
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Comerciante / Administrador

## Descripción
El sistema deberá permitir registrar la ubicación de los establecimientos.

## Criterios de aceptación
1. La ubicación se asocia a un restaurante.
2. Los datos de ubicación pueden actualizarse por un actor autorizado.
3. La aplicación puede consultar la ubicación registrada.
