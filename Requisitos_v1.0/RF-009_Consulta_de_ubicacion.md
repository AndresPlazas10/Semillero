# RF-009 — Consulta de ubicación
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá permitir al usuario consultar la ubicación del restaurante.

## Criterios de aceptación
1. El restaurante posee una ubicación registrada.
2. El usuario puede visualizar la información de ubicación.
3. La ubicación y la distancia al restaurante se muestran en el detalle; la integración con mapas o navegación externa se evalúa en P1/P2 (decisión Sprint 0).

## Estado
Validado en Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
