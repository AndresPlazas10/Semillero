# RIA-001 — Personalización
**Tipo:** Requisito de inteligencia artificial  
**Prioridad:** Alta

## Descripción
El sistema de recomendación deberá utilizar información relacionada con el usuario para producir recomendaciones personalizadas.

## Criterios de aceptación
1. El motor recibe información del usuario disponible para personalización.
2. La salida varía cuando existen diferencias relevantes en las preferencias o interacciones.
3. La personalización puede evaluarse experimentalmente.

## Decisión (Sprint 0)
La personalización se basa en preferencias explícitas, historial ponderado (representación del usuario), rango de precio y ubicación aproximada de la consulta (V-03, V-20).
