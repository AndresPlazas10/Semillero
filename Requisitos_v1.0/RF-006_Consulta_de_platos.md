# RF-006 — Consulta de platos
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá permitir visualizar los platos asociados a cada restaurante.

## Criterios de aceptación
1. Cada restaurante puede mostrar sus platos registrados.
2. El usuario puede seleccionar un plato.
3. La información mostrada corresponde al restaurante seleccionado.
