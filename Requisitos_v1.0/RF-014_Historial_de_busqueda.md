# RF-014 — Historial de búsqueda
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario / Sistema

## Descripción
El sistema deberá almacenar las búsquedas relevantes realizadas por el usuario cuando este haya autorizado dicha funcionalidad.

## Criterios de aceptación
1. Las búsquedas definidas como relevantes pueden registrarse.
2. El historial se asocia al usuario correspondiente.
3. Se aplican las reglas de privacidad y consentimiento definidas para el proyecto.
