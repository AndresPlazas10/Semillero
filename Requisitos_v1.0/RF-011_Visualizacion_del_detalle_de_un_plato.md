# RF-011 — Visualización del detalle de un plato
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá permitir consultar información detallada de un plato.

## Criterios de aceptación
1. El usuario puede acceder al detalle desde un restaurante o resultado de búsqueda.
2. El detalle identifica el plato.
3. El detalle muestra el precio cuando esté registrado.
4. La descripción, imagen, categoría y disponibilidad se muestran cuando existan (validado en Sprint 0).
