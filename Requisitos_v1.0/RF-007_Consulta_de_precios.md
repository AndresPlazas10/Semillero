# RF-007 — Consulta de precios
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá mostrar el precio correspondiente a los platos disponibles en el catálogo.

## Criterios de aceptación
1. Cada plato que tenga precio registrado muestra su precio.
2. El precio se relaciona con el plato correspondiente.
3. El formato de presentación es consistente.
