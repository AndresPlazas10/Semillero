# RF-019 — Gestión de restaurantes
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Comerciante / Administrador

## Descripción
El sistema deberá permitir gestionar los establecimientos registrados.

## Operaciones a definir
- Crear.
- Consultar.
- Actualizar.
- Desactivar/eliminar según reglas de negocio.

## Decisión (Sprint 0)
Permisos: el Gestor administra su restaurante; el Administrador aprueba, valida y puede suspender. El alta queda en estado pendiente hasta la aprobación (V-01, V-02).

## Estado
Validado en Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
