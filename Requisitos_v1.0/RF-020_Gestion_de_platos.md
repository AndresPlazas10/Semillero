# RF-020 — Gestión de platos
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Comerciante / Administrador

## Descripción
El sistema deberá permitir gestionar los platos asociados a los restaurantes.

## Criterios de aceptación
1. Un actor autorizado puede crear un plato.
2. Puede actualizar sus datos.
3. Puede asociarlo a un restaurante.
4. Puede retirarlo o desactivarlo según las reglas definidas.
