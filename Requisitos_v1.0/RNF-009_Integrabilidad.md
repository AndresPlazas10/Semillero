# RNF-009 — Integrabilidad
**Tipo:** Requisito no funcional  
**Prioridad:** Alta

## Descripción
El sistema deberá permitir la comunicación entre la aplicación móvil, la base de datos y el componente de recomendaciones.

## Criterios de aceptación
1. Se documentan las interfaces de comunicación.
2. Los formatos de datos están definidos.
3. Los errores de integración se gestionan.
4. Se realizan pruebas de integración.

## Decisión (Sprint 0)
La comunicación móvil–backend–recomendador se realiza a través de FastAPI; el contrato de API se define en Sprint 0 (S0-08) (V-11).

## Estado
Validado en Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
