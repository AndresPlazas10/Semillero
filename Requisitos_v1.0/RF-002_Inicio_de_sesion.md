# RF-002 — Inicio de sesión
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá permitir que los usuarios registrados inicien y cierren sesión.

## Criterios de aceptación
1. El usuario puede introducir sus credenciales.
2. El sistema valida las credenciales.
3. El usuario autenticado accede a las funciones correspondientes.
4. El usuario puede cerrar sesión.
5. Las credenciales incorrectas generan un mensaje de error.

## Dependencias
- RF-001.
- Servicio de autenticación.
