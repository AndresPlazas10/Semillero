# RF-010 — Búsqueda gastronómica
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá permitir buscar restaurantes y/o platos mediante criterios definidos durante el análisis detallado.

## Criterios de aceptación
1. El usuario puede introducir un criterio de búsqueda.
2. El sistema devuelve resultados relacionados.
3. Los resultados pueden conducir al detalle correspondiente.

## Filtros definidos (Sprint 0)
MVP: tipo de comida, rango de precio y radio de cercanía (ubicación actual). "Abierto ahora" se aplica como regla de disponibilidad del motor, no como filtro. Horario, categoría y filtros por restaurante/plato pasan a P1/P2 (V-04).

Validado en Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
