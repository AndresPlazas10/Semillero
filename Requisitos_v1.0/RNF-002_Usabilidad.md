# RNF-002 — Usabilidad
**Tipo:** Requisito no funcional  
**Prioridad:** Alta

## Descripción
La aplicación deberá proporcionar una interfaz clara, intuitiva y fácil de utilizar.

## Criterios de aceptación
1. Las tareas principales pueden realizarse sin pasos innecesarios.
2. La navegación es consistente.
3. Se realizan pruebas de usabilidad durante la evaluación.
4. Los resultados se documentan.
