# RNF-004 — Escalabilidad
**Tipo:** Requisito no funcional  
**Prioridad:** Alta

## Descripción
La arquitectura deberá permitir incorporar nuevos usuarios, restaurantes, funcionalidades y componentes sin requerir una reconstrucción completa del sistema.

## Criterios de aceptación
La arquitectura deberá separar componentes y responsabilidades de forma que puedan evolucionar independientemente cuando sea viable.
