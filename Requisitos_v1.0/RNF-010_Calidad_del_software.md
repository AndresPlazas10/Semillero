# RNF-010 — Calidad del software
**Tipo:** Requisito no funcional  
**Prioridad:** Alta

## Descripción
El sistema deberá considerar atributos de calidad de software apropiados para evaluar su funcionamiento.

## Referencia
El anteproyecto contempla ISO/IEC 25010:2023 como referencia bibliográfica.

## Decisión (Sprint 0)
Se evaluarán adecuación funcional, eficiencia de desempeño, usabilidad y seguridad, con indicadores ligados a las pruebas del backlog (P-XXX-*), según ISO/IEC 25010 (V-16).

## Estado
Validado en Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
