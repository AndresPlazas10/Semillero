# RF-017 — Presentación de recomendaciones
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
La aplicación deberá mostrar al usuario los restaurantes y/o platos recomendados.

## Criterios de aceptación
1. Las recomendaciones se presentan dentro de la aplicación.
2. Cada recomendación identifica el restaurante o plato correspondiente.
3. El usuario puede acceder al detalle del elemento recomendado.
4. El estado de ausencia de recomendaciones se gestiona de forma comprensible.

## Decisión (Sprint 0)
La presentación principal es de restaurantes recomendados; los platos se muestran como contenido del restaurante (V-19).
