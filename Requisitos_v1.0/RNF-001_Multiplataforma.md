# RNF-001 — Multiplataforma
**Tipo:** Requisito no funcional  
**Prioridad:** Alta

## Descripción
La aplicación deberá estar diseñada para permitir su ejecución en más de una plataforma móvil.

## Criterios de aceptación
La arquitectura y tecnología seleccionadas deberán permitir el desarrollo multiplataforma previsto por el proyecto.

## Referencia del anteproyecto
Se plantea una arquitectura multiplataforma para Android e iOS.

## Decisión (Sprint 0)
React Native + Expo + TypeScript con Expo SDK 57: Android 7+ e iOS 16.4+ (ADR-001). La App Store exige Xcode 26+ desde abril de 2026 (V-12).

## Estado
Validado en Sprint 0 (septiembre de 2026). Ver `../Sprint_0_Plan_v1.0/Acta_Validacion_Sprint_0_v1.0.md`.
