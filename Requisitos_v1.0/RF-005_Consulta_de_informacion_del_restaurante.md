# RF-005 — Consulta de información del restaurante
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá mostrar información detallada de cada restaurante, incluyendo como mínimo nombre, descripción, ubicación, horarios y menú.

## Criterios de aceptación
1. El detalle muestra el nombre del restaurante.
2. Muestra descripción cuando exista.
3. Muestra ubicación.
4. Muestra horarios.
5. Permite acceder al menú o platos asociados.

## Dependencias
- RF-004.
- Datos de restaurantes.
