# RF-008 — Consulta de horarios
**Tipo:** Requisito funcional  
**Prioridad:** Alta  
**Actor principal:** Usuario final

## Descripción
El sistema deberá mostrar los horarios de atención de los restaurantes.

## Criterios de aceptación
1. El horario aparece asociado al restaurante.
2. El formato permite identificar los días y horas de atención.
3. El sistema contempla la posibilidad de restaurantes con diferentes horarios por día.
