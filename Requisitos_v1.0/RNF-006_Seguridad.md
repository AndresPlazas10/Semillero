# RNF-006 — Seguridad
**Tipo:** Requisito no funcional  
**Prioridad:** Alta

## Descripción
El sistema deberá proteger la información de autenticación y los datos asociados a los usuarios.

## Criterios de aceptación
1. Las credenciales no se almacenan de forma insegura.
2. Se aplican controles de acceso.
3. Los componentes de comunicación se configuran de forma segura.
4. Los permisos se definen por rol.
