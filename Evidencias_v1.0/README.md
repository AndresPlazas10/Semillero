# Evidencias del proyecto

Carpeta de registro continuo del proyecto **Aplicación móvil con IA para recomendación gastronómica en Tunja**. Los documentos están en Markdown con títulos y tablas para mantenerlos editables y facilitar su posterior revisión y exportación a Microsoft Word.

## Archivos

- `Bitacora_Sprints_v1.0.md`: objetivos, alcance, trabajo realizado, verificaciones, resultados, decisiones y retrospectiva de cada sprint.
- `Registro_Experimentos_Recomendador_v1.0.md`: protocolo y ficha para cada entrenamiento, evaluación o experimento del recomendador.

## Cómo mantener las evidencias

1. Al iniciar un sprint, confirmar el objetivo, historias comprometidas, responsables, fechas y estimaciones.
2. Durante el sprint, añadir enlaces a PR, commits, capturas, ejecuciones de pruebas y decisiones. No esperar al cierre para reunir evidencias.
3. Al cerrar, completar resultados reales y retrospectiva. Solo contar puntos de historia que cumplieron su Definition of Done.
4. Para cada corrida experimental, crear un registro nuevo en el documento de experimentos; no sobrescribir resultados anteriores.
5. Distinguir resultados sintéticos (validación técnica) de resultados reales (validación experimental). No reportar métricas que no se hayan calculado.
6. No incluir contraseñas, tokens, claves de servicio, datos personales identificables ni coordenadas exactas de usuarios.

## Preparación para Word

Los encabezados `#`, `##` y `###` representan niveles de título; las tablas contienen información tabular. Para preparar el informe, abrir o importar estos documentos en una herramienta compatible con Markdown y guardarlos como `.docx`, o copiar el contenido a Word aplicando los estilos **Título 1**, **Título 2** y **Título 3**. Revisar saltos de página, tablas y enlaces antes de entregar.

## Convención de estados

- **Planificado:** aprobado para el sprint, todavía sin ejecución.
- **En curso:** trabajo iniciado y aún no cerrado.
- **Completado:** existe evidencia verificable y se cumplen los criterios acordados.
- **Bloqueado:** depende de una condición externa o decisión pendiente.
- **Pendiente de verificación:** el trabajo puede existir, pero falta evidencia suficiente para declararlo completado.
