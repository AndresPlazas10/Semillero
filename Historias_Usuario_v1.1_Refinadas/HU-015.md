# HU-015 — Consultar historial de búsqueda

**Prioridad:** Media  
**Trazabilidad:** RF-014, RIA-002  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** El historial requiere consentimiento y alimenta las preferencias inferidas (V-05, V-15).

## Historia de usuario

**Como** usuario  
**Quiero** consultar su historial  
**Para** facilitar futuras consultas y recomendaciones

## Criterios de aceptación

1. Cuando el usuario realiza una búsqueda, entonces el evento se almacena conforme al alcance definido.
2. Cuando consulta su historial, entonces solo visualiza información correspondiente a su cuenta.
3. El sistema permite gestionar el historial según las reglas de privacidad y alcance que se definan.
