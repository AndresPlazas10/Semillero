# HU-014 — Registrar preferencias

**Prioridad:** Alta  
**Trazabilidad:** RF-013, RIA-001  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Preferencias explícitas en onboarding + inferidas progresivamente desde las interacciones (V-06).

## Historia de usuario

**Como** usuario  
**Quiero** registrar preferencias gastronómicas  
**Para** recibir recomendaciones más relevantes

## Criterios de aceptación

1. Cuando el usuario selecciona preferencias válidas, entonces el sistema las guarda.
2. Cuando modifica una preferencia, entonces el nuevo valor queda persistido.
3. Las preferencias quedan disponibles para el proceso de recomendación.
