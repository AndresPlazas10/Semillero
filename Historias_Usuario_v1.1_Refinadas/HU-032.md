# HU-032 — Seguridad de acceso

**Prioridad:** Alta  
**Trazabilidad:** RNF-006  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

## Historia de usuario

**Como** usuario  
**Quiero** proteger su cuenta  
**Para** evitar accesos no autorizados

## Criterios de aceptación

1. Las credenciales no se almacenan de forma insegura.
2. Las operaciones protegidas requieren autenticación.
3. Los permisos se verifican en las operaciones administrativas.
4. Las pruebas de acceso no autorizado son rechazadas.
