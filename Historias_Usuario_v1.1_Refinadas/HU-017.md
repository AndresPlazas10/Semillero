# HU-017 — Integrar motor de recomendación

**Prioridad:** Alta  
**Trazabilidad:** RF-016, RIA-003, RNF-009  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** El motor Python se integra como módulo interno tras FastAPI (V-11).

## Historia de usuario

**Como** sistema  
**Quiero** comunicar la aplicación con el motor de recomendación  
**Para** obtener resultados mediante una interfaz controlada

## Criterios de aceptación

1. Cuando la aplicación solicita recomendaciones con una petición válida, entonces la API procesa la solicitud.
2. Cuando el motor responde correctamente, entonces la API devuelve una estructura de respuesta definida.
3. Ante errores de servicio, entonces la aplicación recibe una respuesta controlada y no se bloquea.
4. Las interfaces quedan documentadas.
