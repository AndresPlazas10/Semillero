# HU-001 — Registro de usuario

**Prioridad:** Alta  
**Trazabilidad:** RF-001  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

## Historia de usuario

**Como** usuario  
**Quiero** crear una cuenta en la aplicación  
**Para** acceder a funcionalidades personalizadas

## Criterios de aceptación

1. Dado que no existe una cuenta con el identificador ingresado, cuando el usuario completa los campos obligatorios y confirma, entonces el sistema valida y crea la cuenta.
2. Dado que faltan datos obligatorios o hay datos inválidos, cuando el usuario intenta registrarse, entonces el sistema informa los errores y no crea la cuenta.
3. Dado que ya existe una cuenta con el identificador registrado, cuando intenta registrarse nuevamente, entonces el sistema informa que no puede duplicarse.
