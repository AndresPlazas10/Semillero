# HU-010 — Buscar opciones gastronómicas

**Prioridad:** Alta  
**Trazabilidad:** RF-010  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Filtros MVP: tipo de comida, rango de precio y radio de cercanía; "abierto ahora" como regla de disponibilidad (V-04).

## Historia de usuario

**Como** usuario  
**Quiero** buscar restaurantes o platos  
**Para** encontrar rápidamente opciones de interés

## Criterios de aceptación

1. Cuando el usuario introduce un término válido, entonces el sistema devuelve resultados relacionados.
2. Cuando no existen coincidencias, entonces informa que no hay resultados.
3. La búsqueda no debe devolver entidades que no correspondan al término según las reglas definidas.

## Dependencias

- Requisitos relacionados indicados en la trazabilidad.
- Modelo de datos y arquitectura deberán definir los detalles técnicos.
- Las reglas no especificadas deberán cerrarse durante el refinamiento técnico.
