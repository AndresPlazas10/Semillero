# HU-019 — Actualizar información gastronómica

**Prioridad:** Alta  
**Trazabilidad:** RF-018  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Gestión desde la app móvil con rol Gestor; aprobación y estados por el Administrador (V-01, V-02).

## Historia de usuario

**Como** administrador/gestor  
**Quiero** actualizar información gastronómica  
**Para** mantener el catálogo vigente

## Criterios de aceptación

1. Cuando un gestor autorizado modifica información válida, entonces el sistema persiste los cambios.
2. Los datos actualizados se reflejan en las consultas posteriores.
3. Un usuario sin permisos no puede realizar la modificación.
