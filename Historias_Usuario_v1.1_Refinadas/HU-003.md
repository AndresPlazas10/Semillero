# HU-003 — Gestión del perfil

**Prioridad:** Media  
**Trazabilidad:** RF-003, RIA-001  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Perfil sin zona habitual: nombre/apodo, rango de precio, preferencias alimentarias y restricciones (V-03).

## Historia de usuario

**Como** usuario  
**Quiero** consultar y actualizar su perfil  
**Para** mantener sus datos actualizados

## Criterios de aceptación

1. Dado que el usuario está autenticado, cuando consulta su perfil, entonces visualiza los datos permitidos.
2. Cuando modifica un campo editable con datos válidos y guarda, entonces los cambios quedan persistidos.
3. Cuando los datos no cumplen las validaciones, entonces el sistema informa el error y conserva los datos anteriores.
