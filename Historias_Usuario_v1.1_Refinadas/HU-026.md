# HU-026 — Entrenamiento y evaluación del modelo

**Prioridad:** Alta  
**Trazabilidad:** RIA-004  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Prioridad P0. Sintético para pipeline; real para validación experimental; split temporal (V-09, V-17).

## Historia de usuario

**Como** investigador/desarrollador  
**Quiero** separar datos de entrenamiento y evaluación  
**Para** medir el modelo de forma controlada

## Criterios de aceptación

1. Existe un conjunto destinado a entrenamiento y otro a evaluación.
2. Los datos de evaluación no se utilizan indebidamente para entrenar.
3. El proceso es reproducible según la configuración documentada.
4. Los resultados de evaluación quedan registrados.
