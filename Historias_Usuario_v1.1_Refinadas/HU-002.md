# HU-002 — Inicio de sesión

**Prioridad:** Alta  
**Trazabilidad:** RF-002, RNF-006  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

## Historia de usuario

**Como** usuario  
**Quiero** iniciar sesión  
**Para** acceder de forma segura a su cuenta

## Criterios de aceptación

1. Dado que las credenciales son válidas, cuando el usuario inicia sesión, entonces el sistema autentica y permite acceder.
2. Dado que las credenciales son incorrectas, cuando intenta iniciar sesión, entonces el acceso es rechazado y se muestra un mensaje comprensible.
3. Dado que el acceso es exitoso, entonces la sesión queda gestionada mediante el mecanismo de autenticación definido.
