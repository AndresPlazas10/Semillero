# HU-013 — Registrar interacción

**Prioridad:** Alta  
**Trazabilidad:** RF-012, RIA-002  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Se definen 5 eventos con metadatos de atribución, incluida la impresión de recomendación (V-05).

## Historia de usuario

**Como** usuario  
**Quiero** registrar sus interacciones con restaurantes y platos  
**Para** aportar información para personalizar recomendaciones

## Criterios de aceptación

1. Cuando ocurre una interacción incluida en el modelo de datos, entonces el sistema registra el evento definido.
2. La interacción queda asociada al usuario cuando este está identificado.
3. El registro de la interacción no impide la navegación ni genera una duplicación indebida según las reglas definidas.
