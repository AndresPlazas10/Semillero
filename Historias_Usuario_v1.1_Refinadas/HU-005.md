# HU-005 — Detalle del restaurante

**Prioridad:** Alta  
**Trazabilidad:** RF-005  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

## Historia de usuario

**Como** usuario  
**Quiero** consultar información de un restaurante  
**Para** evaluar una opción gastronómica

## Criterios de aceptación

1. Cuando el usuario selecciona un restaurante, entonces se muestra su información registrada.
2. El detalle permite acceder a sus platos.
3. La ubicación y los horarios se muestran cuando existen datos registrados.
