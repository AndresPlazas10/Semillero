## Historia de usuario

**Como** usuario  
**Quiero** visualizar las recomendaciones  
**Para** decidir qué opción consultar

## Criterios de aceptación

1. Cuando existen recomendaciones válidas, entonces se muestran de forma clara.
2. Cada recomendación permite acceder al detalle correspondiente.
3. Cuando no existen recomendaciones, entonces se muestra un estado vacío comprensible.
