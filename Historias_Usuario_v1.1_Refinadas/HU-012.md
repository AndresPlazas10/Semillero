# HU-012 — Detalle de plato

**Prioridad:** Alta  
**Trazabilidad:** RF-011  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

## Historia de usuario

**Como** usuario  
**Quiero** consultar el detalle de un plato  
**Para** evaluar una opción antes de elegirla

## Criterios de aceptación

1. Cuando selecciona un plato, entonces visualiza su información registrada.
2. El detalle muestra el precio cuando existe.
3. El usuario puede regresar al restaurante sin perder el contexto de navegación.
