# HU-020 — Gestionar restaurantes

**Prioridad:** Alta  
**Trazabilidad:** RF-019  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Gestión desde la app móvil con rol Gestor; aprobación y estados por el Administrador (V-01, V-02).

## Historia de usuario

**Como** administrador/gestor  
**Quiero** crear, consultar y actualizar restaurantes  
**Para** administrar el catálogo gastronómico

## Criterios de aceptación

1. Un gestor autorizado puede crear un restaurante con los datos obligatorios.
2. Puede consultar y actualizar restaurantes existentes.
3. Los datos inválidos son rechazados.
4. Las operaciones respetan los permisos definidos.
