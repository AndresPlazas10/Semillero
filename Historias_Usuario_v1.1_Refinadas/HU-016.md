# HU-016 — Generar recomendaciones

**Prioridad:** Alta  
**Trazabilidad:** RF-015, RIA-001, RIA-002, RIA-003  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Unidad principal: restaurante; los cerrados se excluyen o penalizan; cold start sin zona declarada (V-04, V-08, V-19). Para el MVP depende solo de **HU-013 y HU-014** (sin historial de búsqueda ni entrenamiento, que pasan a Incremento 2).

## Historia de usuario

**Como** usuario  
**Quiero** recibir recomendaciones personalizadas  
**Para** descubrir restaurantes o platos de interés

## Criterios de aceptación

1. Dado que existen datos suficientes, cuando se solicita una recomendación, entonces el motor devuelve resultados válidos.
2. Las recomendaciones utilizan las variables aprobadas para el modelo.
3. Si los datos son insuficientes, entonces se aplica la estrategia de cold start definida.
4. El sistema no presenta recomendaciones de entidades inexistentes o no disponibles.
