**Prioridad:** Alta  
**Trazabilidad:** RIA-005  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Cold start: cercanía + preferencias explícitas; sin ubicación o historial → popularidad (V-08).

## Historia de usuario

**Como** usuario nuevo  
**Quiero** recibir recomendaciones sin historial  
**Para** descubrir opciones desde la primera interacción

## Criterios de aceptación

1. Cuando el usuario no tiene historial suficiente, el sistema identifica la condición de cold start.
2. Se aplica la estrategia definida para usuarios nuevos.
3. Se presentan recomendaciones o alternativas iniciales válidas.
4. La estrategia queda documentada para poder evaluarla.
