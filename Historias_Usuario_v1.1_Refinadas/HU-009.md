# HU-009 — Consultar ubicación

**Prioridad:** Alta  
**Trazabilidad:** RF-009  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Se muestra ubicación y distancia; la integración con mapas queda en P1/P2 (RF-009).

## Historia de usuario

**Como** usuario  
**Quiero** consultar la ubicación  
**Para** saber dónde se encuentra el restaurante

## Criterios de aceptación

1. Cuando existe ubicación registrada, entonces se muestra asociada al restaurante.
2. La información permite identificar la ubicación conforme al mecanismo definido para el MVP.
3. Si no existe ubicación, se informa su indisponibilidad.
