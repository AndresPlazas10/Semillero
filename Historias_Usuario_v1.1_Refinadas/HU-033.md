# HU-033 — Privacidad de datos

**Prioridad:** Alta  
**Trazabilidad:** RNF-007  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

## Historia de usuario

**Como** usuario  
**Quiero** tener un tratamiento adecuado de sus datos e interacciones  
**Para** proteger su información

## Criterios de aceptación

1. Se documentan los datos personales tratados.
2. Se documenta el propósito de su uso.
3. El acceso a datos está restringido según el rol.
4. El tratamiento de datos del recomendador se limita a lo necesario para el alcance aprobado.
