# HU-023 — Gestionar ubicación

**Prioridad:** Media  
**Trazabilidad:** RF-022  
**Estado:** Validada en Sprint 0 (septiembre de 2026) — ver Acta de Validación

**Decisión Sprint 0:** Gestión desde la app móvil con rol Gestor; aprobación y estados por el Administrador (V-01, V-02).

## Historia de usuario

**Como** administrador/gestor  
**Quiero** gestionar la ubicación del restaurante  
**Para** mantener correcta la información geográfica

## Criterios de aceptación

1. Puede registrar una ubicación válida.
2. Puede actualizarla.
3. La ubicación queda asociada al restaurante correcto.
4. La ubicación actualizada se refleja en la vista del usuario.
